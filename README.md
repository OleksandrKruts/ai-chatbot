# AI Chatbot

A modern AI chat application built with **Next.js 15** and **Groq API**, featuring real-time streaming responses.

🔗 **Live Demo:** [AI Chatbot](https://ai-chatbot-theta-lilac-46.vercel.app/chat)

---

## Overview

This project is an AI-powered chatbot that provides instant, streaming responses similar to ChatGPT.  
It uses Groq’s LLaMA 3 model and Server-Sent Events for real-time interaction.

---

## Key Features

- Real-time AI responses (streaming)
- Multi-turn conversation support
- Clean, minimal chat interface
- Fast inference via Groq API
- Secure server-side API handling

---

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Groq API (LLaMA 3.3 70B)
- Server-Sent Events (SSE)
- React

---

## How to run

```bash
npm install
npm run dev
```

Open:  
http://localhost:3000

---

## Purpose

Built as a portfolio project to demonstrate working with LLM APIs, streaming responses, and modern Next.js architecture.
